## 附加赛

#### T1

![](https://img2023.cnblogs.com/blog/3186835/202309/3186835-20230901154123964-2091679024.png)

![](https://img2023.cnblogs.com/blog/3186835/202309/3186835-20230901154136248-1643610557.png)

题意简化即 $f(x)$ 表示 $x$ 每一位数的平方和

我们可以发现 $f(x)$ 的值其实是极小的，只有 $9^2\times 18$ 种（每个数最大是 $9^2$ 一共 $18$ 位，所以和最大为 $9^2\times 18$ ）

然后我们就可以直接枚举 $f(x)$ 的值了

那么现在的 $x$ 就是 $f(x)\times K$ ，想让 $x=f(x)\times K$ ，将 $x$ 带入也就是想让 $f(x)\times K=f(f(x)\times K)$ ，所以枚举完统计一下个数即可

```cpp
const int INF=1e9+7;

int k,l,r;

int f(int x)
{
    int sum=0;
    while(x)
    {
        sum+=(x%10)*(x%10);
        x/=10;
    }
    return sum;
}

int solve(int n)
{
    int ans=0;
    for (int fx=1;fx<=1500;fx++)
    {
        int i=fx*k;
        if (i>n) break;
        ans+=f(i)==fx;
    }
    return ans;
}

signed main(){
    int T=read();
    while(T--)
    {
        k=read(),l=read(),r=read();
        printf("%lld\n",solve(r)-solve(l-1));
    }
    return 0;
}
```

第二题的题意很明了，想让我们用最少得的价值，让 $|X|$ 和 $|Y|$  不联通，因为在一棵树上，而且让价值最少，能想到树形 $dp$ （~~别问我为啥考场上没想到，说明做的少了~~ ），现在思考一下需要解决的是什么问题，让 $|X|$ 和 $|Y|$ 不联通，那我们可以设 $f_u$ 表示 $u$ 这个点为 $x$ ，子树内  $|X|$ 和 $|Y|$ 不联通需要的最小价值，$g_u$ 则为 $u$ 这个点为 $y$ 子树的最小价值

转移就简单的多

若 $u$ 为 $x$ 

1. $v$ 为 $x$ 则 $f_u=f_u+f_v$
2. $v$ 为 $y$ 则 $f_u=f_u+g_v+w$

若 $u$ 为 $y$

1. $v$ 为 $y$ 则 $g_u=g_u+g_v$ 
2. $v$ 为 $x$ 则 $g_u=g_u+f_v+w$

取 $min$ 即可，但是需要保证一点：为 $u$ 为 $x$ 时，转移时是不能从 $g_u$ 转移的（不懂得看定义），所以直接设 $g_u$ 为 INF 即可，$u$ 为 $y$ 时同理

```cpp
const int INF=1e18+7;
const int N=1e5+7;

int g[N],f[N],n;
bool a[N],b[N];
vector<PII> G[N];

void dfs(int u,int fa)
{
    if (a[u]) g[u]=INF;
    if (b[u]) f[u]=INF;
    for (auto v:G[u])
    {
        if (v.fi==fa) continue;
        dfs(v.fi,u);
        f[u]=min(f[u]+f[v.fi],f[u]+g[v.fi]+v.se);
        g[u]=min(g[u]+g[v.fi],g[u]+f[v.fi]+v.se);
    }
}

signed main(){
    scanf("%lld",&n);
    int a1=read();
    for (int i=1;i<=a1;i++) a[read()]=1;
    a1=read();for (int i=1;i<=a1;i++) b[read()]=1;
    for (int i=1;i<n;i++)
    {
        int u=read(),v=read(),w=read();
        G[u].p_b(m_p(v,w));
        G[v].p_b(m_p(u,w));
    }
    dfs(1,0);
    printf("%lld\n",min(f[1],g[1]));
    return 0;
}
```
