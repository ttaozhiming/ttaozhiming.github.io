## A.区间逆序对

### 题目描述：

有一个长度为 $n$ 的序列 $a$，进行 $m$ 次询问，每次询问给定 $l,r$，求有多少组 $i,j$ 满足 $l\le i<j \le r，a_i>a_j$。

对于 $100\%$ 的数据，$1\le n,m\le10^6$，$1\le l<r\le n$，$i\in[1,n]$，$a_i\le50$

### 题目分析：

第一思路：板子题，直接莫队就做完了，$n\sqrt{n}$ 即可。

然后发现 $n\le1e6$，直接崩溃，看到 $a_i\le 50$，发现莫队的统计答案已经是 $O(1)$ 的，没法优化，那只能换一种思路。

思考对于一个询问，设 $cnt[i][j]$ 表示 $a_{1\sim i}$ 中比 $j$ 大的数的个数，答案即为：
$$
\sum_{i=l}^{r}cnt[i][a_i]-cnt[l][a_i]
$$
 我们把他拆开看：
$$
\sum_{i=1}^{r}cnt[i][a_i]-\sum_{i=1}^{l-1}cnt[i][a_i]-\sum_{i=l}^{r}cnt[l][a_i]
$$
前一半可以直接通过前缀和求出，后一段也可以通过一个二维数组求出，枚举颜色求解即可。

###  代码：

```cpp
int t[N][53],f[N][53];
LL sum[N];
int n,a[N],m;

signed main(){
    // t[i][j]: 1~i 中有多少个比 j 大的数
    // f[i][j]: 1~i 中出现过多少次 j
    scanf("%d%d",&n,&m);
    for (int i=1;i<=n;i++){
        a[i]=read();
        for (int j=1;j<a[i];j++) t[i+1][j]++;
        for (int j=1;j<=50;j++) t[i][j]+=t[i-1][j],f[i][j]+=f[i-1][j];
        f[i][a[i]]++;
    }
    for (int i=1;i<=n;i++) sum[i]=sum[i-1]+t[i][a[i]];
    for (int i=1;i<=m;i++){
        int l=read(),r=read();
        LL ans=sum[r]-sum[l-1];
        for (int j=1;j<=50;j++) ans-=1ll*(f[r][j]-f[l-1][j])*t[l][j];
        printf("%lld\n",ans);
    }
    return 0;
}
```

## B.排列

### 题目描述：

给定一个 $1\sim n$ 的排列 $a$。

在一个初始为空的序列 $b$，你可以任意次操作，每次操作为以下三种之一：

- 把整个序列左移一位，$a_1$ 转到 $a_n$。
- 把整个序列右移一位，$a_n$ 转到 $a_1$。
- 选择一个 $i\in[1,m]$，并把 $a_i$ 加到 $b$ 的末尾。

小 $L$ 希望通过进行一次操作使得 $b$ 的长度为 $n$，并且从前往后分别是 $1\sim n$。

你需要求出最少需要多少次**前两次操作**。

对于 $100\%$ 的数据，$1\le m \le n \le 5\times 10^5$。

### 题目分析：

要求最优解，发现组合数做不了，所以想到 dp。

第一想法是设 $dp[i][j]$ 表示填到 $i$ 这个数了，向右转了 $j$ 次。

dp 转移好写的。[Code](https://www.luogu.com.cn/paste/vuec8qhu) 

**正解**：

假设现在 $b$ 中已经有了 $1\sim k-1$，考虑如何加入 $k$。

如果 $k$ 已经在 $1,m$ 中出现过了，直接执行三操作即可。

否则需要不断地一操作和二操作，直到 $k$ 出现在 $[1,m]$ 中，在这种情况下一定是 $a_1=k$ 或者 $a_m=k$。

因为我们可以进行 dp：设 $dp_{i,0/1}$ 表示当前 $b$ 中已经有了 $1\sim i$，第二维为 $0$ 时要求 $a_1=i$，为 $1$ 时要求 $a_m=i$。

转移时只需要找到一个 $k'$，满足 $k'$ 是不在 $[1,m]$ 内的最小的大于 $k$ 的数，转移到 $dp_{k',0/1}$ 即可。

求 $k'$ 时可用可以删除前驱和后缀的数据结构解决即可，时间复杂度 $O(n\log n)$。

### 代码：

代码可能比较难理解，我来讲解一下。

首先 $o[i][0/1]$ 表示 $i$ 这个数，在 $pos_i$ 这个位置，所在 $[1,m]$ 区间的左端点/右端点，区间外的第一个大于 $i$  的数。

这个东西是需要预处理的，所以我们去枚举区间，每次加入 $a[i]$ 去掉 $a[i+m]$，因为要找的是区间之外的最小的大于 $k$ 的数。

然后就是 $dp$ 的转移，这里推荐最好画个图理解一下。以下图中黑色的区间为当前的 $[1,m]$ 区间，绿色为转移之后的 $[1,m]$ 区间。

LL ans=INF,dp[N][2];
int n,m,a[N],pos[N],o1,o[N][2];
set<int> s;

int dis(int x,int y){if (x>y) swap(x,y);return min(y-x,n+x-y);}
void gmin(LL &x,LL y){x=min(x,y);}

signed main(){
    scanf("%d%d",&n,&m);
    for (int i=1;i<=n;i++)
        scanf("%d",&a[i]),pos[a[i]]=i,dp[i][0]=dp[i][1]=INF;
    for (int i=m+1;i<=n;i++) s.insert(a[i]);s.insert(n+1);o1=*s.begin();
    for (int i=1;i<=n;i++){
        int t=a[i];o[t][0]=*s.lower_bound(t);t=a[(i+m-2)%n+1];
        o[t][1]=*s.lower_bound(t);s.insert(a[i]),s.erase(a[(i+m-1)%n+1]);
    }if (o1>n) ans=0;else dp[o1][0]=dis(pos[o1],1),dp[o1][1]=dis(pos[o1],m);
    for (int i=1;i<=n;i++){
        if (o[i][0]>n) gmin(ans,dp[i][0]);
        else{
            gmin(dp[o[i][0]][0],dp[i][0]+dis(pos[i],pos[o[i][0]]));
            gmin(dp[o[i][0]][1],dp[i][0]+dis((pos[i]+m-2)%n+1,pos[o[i][0]]));
        }
        if (o[i][1]>n) gmin(ans,dp[i][1]);
        else{
            gmin(dp[o[i][1]][0],dp[i][1]+dis(pos[i],(pos[o[i][1]]+m-2)%n+1));
            gmin(dp[o[i][1]][1],dp[i][1]+dis(pos[i],pos[o[i][1]]));
        }
    }
    printf("%lld\n",ans);
    return 0;
}

## C.有向图最小环

### 题目描述：

有一个有向图 $G$。$\forall u,v\in[1,n],u\not=v$，如果 $a_{u,v}\not=0$，那么 $G$ 中存在一条 $u\to v$ 的边权为 $a_{u,v}$ 的边，否则 $G$ 中不存在 $u\to v$ 的边。

小 $L$ 想从点 $1$ 沿着 $G$ 中的边走到 $n$，然后再走回 $1$。

你需要求出所有至少经过一次的边的边权和最小值。保证有解。

对于 $100\%$ 的数据，$1\le n \le 200$，$\forall i,j\in[1,n]$，$0\le a_{i,j} \le 10^9$。

### 题目分析：

可以发现，最后的路径一定是这样的

![](https://img2023.cnblogs.com/blog/3186835/202309/3186835-20230912152853005-261293175.png)

其中左边是 $1$ 号点，右边是 $n$ 号点。黑色箭头表示 $1\to n$ 的路径，红色箭头代表一条最短路径从终点走向起点，蓝色箭头表示沿着黑色部分已经经过的路径。

考虑 $dp$，设 $dp_{u,v}$ 表示最后一个蓝色箭头为 $u\to v$ 的答案。那么有：
$$
dp[x2][y2]=dp[x][y]+dis[y][x2]+dis[x2][y2]+dis[y2][x]
$$
但是这样转移没有固定的状态，但是看着像是最短路的模式，所以跑 `dij` 求解。

直接做是 $O(n^4)$ 的。

可以先把前两项转移出来，即 $dp[x][x2]=dp[x][y]+dis[y][x2]$，然后再接着枚举复杂度就变成 $O(n^3)$ 的了，总复杂度为 $O(n^3\log n)$。

### 代码：

```cpp
const int N=200+7,M=N*N*2+2;

int n;
int f[N][N],dis[M];
bool vis[M];
vector<PII> G[M];
priority_queue<PII> q;

int id(int op,int i,int j){
    return op*n*n+(i-1)*n+j;
}

void dij(){
    memset(dis,0x3f,sizeof dis);
    dis[id(0,1,1)]=0;q.push(m_p(0,id(0,1,1)));
    while(!q.empty()){
        int u=q.top().se;q.pop();
        if (vis[u]) continue;vis[u]=1;
        for (auto s:G[u]){
            int v=s.fi,w=s.se;
            if (dis[v]>dis[u]+w){
                dis[v]=dis[u]+w;
                q.push(m_p(-dis[v],v));
            }
        }
    }
}

signed main(){
    scanf("%lld",&n);
    for (int i=1;i<=n;i++){
        for (int j=1;j<=n;j++){
            int x=read();
            if (x) f[i][j]=x;
            else f[i][j]=(i==j)?0:INF;
        }
    }
    for (int k=1;k<=n;k++){
        for (int i=1;i<=n;i++){
            for (int j=1;j<=n;j++){
                f[i][j]=min(f[i][j],f[i][k]+f[k][j]);
            }
        }
    }
    for (int i=1;i<=n;i++){
        for (int j=1;j<=n;j++){
            for (int k=1;k<=n;k++){
                G[id(0,i,j)].p_b(m_p(id(1,i,k),f[j][k]));
            }
        }
    }
    for (int i=1;i<=n;i++){
        for (int j=1;j<=n;j++){
            for (int k=1;k<=n;k++){
                G[id(1,i,j)].p_b(m_p(id(0,j,k),f[j][k]+f[k][i]));
            }
        }
    }
    dij();printf("%lld\n",dis[id(0,n,n)]);
    return 0;
}
```
