## T1

### 题目描述：

小 C 在 $\text{NOI 2023}$ 中将书本合并成了一摞，现在小 C 打算在 $\text{NOIP 2023}$ 考前并掉 这些书中的算法知识。

 小C 摞起的书一共有 $n$ 种，第 $i$ 种书有 $c_i$ 本，读一本种类为 $i$ 的书需要花 $t_i$ 的小 时，读完一本后他将获得 $w_i$ 的收益。 

小 C 很喜欢多重背包问题，所以现在他想考考你，如果花上不超过 $m$ 小时用来读 书，能获得的最大收益和是多少？

对于 $100\%$ 的数据，保证 $n\le 80$，$m\le 10^9$，对于每个 $i$ 满足 $c_i\le 10^9$，$t_i\le 80$，$w_i\le 10^9$。

### 题目分析：

首先看到 $n$ 非常小，上来想到之前做过的一个题，把 $n$ 给对半分，然后 $2^{n/2}$ 枚举，但是发现 $n\le80$，没有前途。

因为每个数的体积都非常小，考虑直接贪心选，按照 $\frac{w_i}{t_i}$ 排序，从大到小选。

比如说 $\frac{w_i}{t_i}<\frac{w_j}{t_j}$，那把 $t_j$ 个物品 $i$ 换成 $t_i$ 个物品 $j$ 显然更优，当时当所有物品的数量都 $<\max \{t\}$ 的时候，就无法交换了，发现这个时候 $c_i\le 80$，所有 $m\le \sum_{i=1}^{n} c_i\times t_i\le512000$，发现背包的空间只需要开到 $512000$ 即可，剩下的贪心。

枚举分给背包的空间，贪心的空间自然也就知道了，对得到的贡献取 $\max$ 即可。

const int INF=1e9+7;
const int W=80,N=82;

int dp[N*W*W],n,m;
vector<PII> v;

struct node{
    int cnt,w,v;//个数 体积 价值
}a[N];
bool operator<(const node &a,const node &b){
    return a.v*b.w>b.v*a.w;
}

signed main(){
    scanf("%lld",&n);
    for (int i=1;i<=n;i++) scanf("%lld",&a[i].cnt);
    for (int i=1;i<=n;i++) scanf("%lld",&a[i].w);
    for (int i=1;i<=n;i++) scanf("%lld",&a[i].v);
    scanf("%lld",&m);
    sort(a+1,a+n+1);
    for (int i=1;i<=n;i++){
        int x=min(a[i].cnt,W);
        for (int j=1;j<=x;j<<=1){
            v.p_b(m_p(j*a[i].w,j*a[i].v));
            x-=j;
        }
        if (x) v.p_b(m_p(x*a[i].w,x*a[i].v));
    }
    for (auto s:v){
        for (int j=N*W*W;j>=s.fi;j--){
            dp[j]=max(dp[j],dp[j-s.fi]+s.se);
        }
    }
    int ans=0;
    for (int i=0;i<=min(m,N*W*W);i++){
        int lft=m-i,sum=0;
        for (int j=1;j<=n;j++){
            int c=min(max(0ll,a[j].cnt-W),lft/a[j].w);
            sum+=c*a[j].v;lft-=c*a[j].w;
        }
        ans=max(ans,dp[i]+sum);
    }
    printf("%lld\n",ans);
    return 0;
}

## T2

### 题目描述：

小 B 八年前看到的桂花树是一张 $n$ 个点 $n−1$ 条边**弱连通有向图**。其中弱联通定义为将有向边看成无向边后原图联通。

小 B 认为，一颗桂花树的脉络越连续，这棵树就生长的越繁荣。于是他定义一颗桂 花树的繁荣值为这棵树上的**有向路径**的条数。

 时过境迁，小 B 遗忘了那天所看到的桂花树的形态。但是他仍然很好奇，对于所有 不同的满足条件的弱联通有向图，它们的繁荣值之和是多少。**答案对 $p$ 取模**。

**有向路径**指得是一条点不重复的路径，对于路径中相邻的两个点，前面的点向后面 的点连着一条有向边。特别地，起点和终点相同的路径也被认为合法。

**点有标号**，两张图被认为是不同的当且仅当存在一条有向边在一张图中出现而在另 一张图中没有。

对于 $100\%$ 的数据，保证：$1\le n \le 10^7$，$p\le 10^9$，$p$ 为质数。**保证** $n< p$。

### 题目分析：

前置：`prufer` 序列一系列知识。

首先肯定要枚举一个 $k$，把所有长度为 $k$ 的答案的贡献都记录下来。

那么现在问题变成了给定了 $k$ 个点，让每个点都形成一棵树，并且所有的点加起来为 $n$ 的方案数。

**做法一**：

如果你知道**广义 Cayley 定理**，题目就可以转化为给你 $k$ 棵树，让 $k$ 个点分别在 $k$ 棵树里的方案数。

答案即为 $k\times k^{n-k-1}$，但是这是无根数的方案。

因为前面我们的 $k$ 个点是已经钦定完的，所以就算是有根树也是 $k\times n^{n-k-1}$。

但是 $k$ 个点可以任选，所以要乘上 $\binom{n}{k}$，并且除了链，以外的边都可以任选方向，所以乘上 $2^{(n-1)-(k-1)}$。

$k$ 个点还可以随机排列，所以答案乘上 $k!$。

方案数即为 $k\times n^{n-k-1}\times \binom{n}{k}\times 2^{(n-1)-(k-1)}\times k!$。

枚举 $k$ 即可。

**注意**，当 $k=n$ 时，答案为 $n!$，特判一下即可。

**做法二**：

前提是你要知道 Cayley 定理，如果一个都不知道，就像我一样，暴力拉满，遗憾离场。

只能做到 $n^2$，听说多项式科技可以搞到 $n\log^2 n$，反正我不会/kk。

还是以长度为 $k$ 的链开始。

也就是说现在要统计 $k$ 个点，每个点再加上一些点，形成树。

假如当前树的点的个数为 $l$，那么能形成的数的个数为 $l^{l-2}$，但是这个可以选的值域其实不止 $l$ 个，考虑设 $dp_{i,j}$ 表示前 $i$ 棵树，总共已经选了 $j$ 个点。

我们枚举 $l$，那么 $dp[i-1][j-l]\to dp[i][j]$，考虑系数怎么处理，首先有一个 $l^{l-2}$，考虑 $l$ 可以在 $n-(j-l)$ 个中选 $l$ 个，然后乘上 $\binom{n-j+l}{l}$，$l-1$ 条边的方向可以随意，乘上一个 $2^{l-1}$，选出来任意一个当根都可以，乘上 $k$。

所以转移为：
$$
dp[i][j]=\sum_{l=1}^{j-i+1}dp[i-1][j-l]\times l^{l-1}\times \binom{n-j+l}{l}\times 2^{l-1}
$$
这样复杂度可以做到 $n^3$，考虑怎么优化，发现整个转移系数和 $i$ 没有一点关系，考虑 $i$ 可不可以去掉。

发现 $\binom{n-j+l}{l}$ 是难搞的，考虑他本质上在干什么，其实就是让 $a_1+a_2+a_3+...=n$，然后求第 $x$ 个可以有多少种选法。

假设我们已经知道了 $a_1,a_2,\cdots,a_m$，那么给每一个点标号后的方案数即为：
$$
\binom{n}{a_1}\times \binom{n-a_1}{a_2}\times \cdots \times \binom{n-a_1-a2-\cdots-a_m-1}{a_m}=\frac{n!}{a_1!\times a_2!\times \cdots\times a_m!}
$$
那么我们这个式子是不是可以转化为：
$$
dp[i]=\sum_{j=0}^{i-1}dp[j]\times l^{l-1}\times \frac{1}{l!}\times 2^{l-1}
$$
最后答案乘上 $n!$ 即可。

为了减小常数，每一个转移系数可以直接预处理。

const int INF=1e9+7;
const int N=1e7+7;

int n,mod;
int fac[N],ifac[N];
int ans=0;

int qmi(int a,int k){
    int res=1;
    while(k){
        if (k&1) res=res*a%mod;
        a=a*a%mod;k>>=1;
    }return res;
}

int C(int n,int m){
    if (n<m) return 0;
    return fac[n]*ifac[n-m]%mod*ifac[m]%mod;
}

void add(int &x,int y){
    x=x+y;
    if (x>=mod) x-=mod;
}

signed main(){
    scanf("%lld%lld",&n,&mod);
    fac[0]=1;
    for (int i=1;i<=n;i++) fac[i]=fac[i-1]*i%mod;
    ifac[n]=qmi(fac[n],mod-2);
    for (int i=n-1;i>=0;i--) ifac[i]=ifac[i+1]*(i+1)%mod;
    for (int i=1;i<n;i++){
        add(ans,qmi(n,n-i-1)%mod*C(n,i)%mod*qmi(2,n-i)%mod*fac[i]%mod*i%mod);
    }
    add(ans,fac[n]);
    printf("%lld\n",ans);
    return 0;
}

const int INF=1e9+7;
const int N=1e6+7;

int n,mod;
int dp[N],fac[N],ifac[N];
int pre[N];

int qmi(int a,int k){
    int res=1;
    while(k){
        if (k&1) res=res*a%mod;
        a=a*a%mod;k>>=1;
    }return res;
}

signed main(){
    scanf("%lld%lld",&n,&mod);
    if (mod==2){
        if (n==1) puts("1");
        else puts("0");
        return 0;
    }
    fac[0]=1;
    for (int i=1;i<=n;i++) fac[i]=fac[i-1]*i%mod;
    ifac[n]=qmi(fac[n],mod-2);
    for (int i=n-1;i>=0;i--) ifac[i]=ifac[i+1]*(i+1)%mod;
    for (int i=1;i<=n;i++){
        pre[i]=qmi(i,i-1)*ifac[i]%mod*qmi(2,i-1)%mod;
    }
    dp[0]=1;
    for (int i=1;i<=n;i++){
        for (int j=0;j<i;j++){
            int k=i-j;
            dp[i]=(dp[i]+dp[j]*pre[k])%mod;
        }
    }
    int ans=dp[n]*fac[n]%mod;
    printf("%lld\n",ans);
    return 0;
}
