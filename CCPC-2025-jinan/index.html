K

题意：

给定 2n2n2n 张卡牌，数字为 111 到 nnn，每个数字的卡牌各有 222 次。 aaa 和 bbb 各自持 nnn 张，两人轮流放置卡牌，aaa 先手。

  • 对于当前选手，如果他放置的卡牌号码，在当前牌堆上已经出现过了，那么他获得 111 分，同时把当前牌堆上两个卡牌号码及其中间的牌都移除。

已知 aaa 的出牌顺序，调整 bbb 的出牌顺序，使得 aaa 的得分最小化。

n≤105n\le 10^5n≤105

分析：

题目本质是扑克牌中的小猫钓鱼，两张相同的牌可以吃掉中间的所有牌。

观察性质：

  • aaa 手里有若干两张，bbb 手里就有相同数量的两张。
  • 只用让 aaa 的得分最小化，而不是求 bbb 的得分最大化，就不用考虑牺牲再得分问题。

所以得出构造方案：

  • 在 aaa 两个相同牌的前面放上 bbb 的相同牌，这样就可以取消 aaa 两张牌得分的情况。
  • 在此基础并且 bbb 后手的情况下，bbb 只需要直接在 aaa 的单张后面按照 aaa 的顺序放入即可。

题意：

给定长度为 nnn 的数组，执行以下过程：

  • 选择当前左边两个数字，取出更大的，作为当前这一轮得分。
  • 将更小的那个元素，放置到数组末尾。

有两种操作：

  • C x y， 交换位置 x,yx,yx,y 的值，1≤x,y≤n1\le x,y\le n1≤x,y≤n。
  • A x y， 查询对于当前数组，第 xxx 轮到第 yyy 轮的得分之和，1≤x≤y<n1\le x\le y<n1≤x≤y<n。

n,m≤105n,m\le 10^5n,m≤105

分析：

既然数据给到 10510^5105，说明操作的查询或者修改一定有一个可以通过数据结构快速的答案，另一个是题目性质自带的复杂度低。

得分之和用数据结构更方便通过数据结构优化（记录每一轮的得分），说明修改操作是可以在 10310^3103 复杂度内实现的。

题意：

给定 nnn 张牌，第 iii 张牌取值范围为 [li,ri][li,ri][li,ri]，给每张牌选一个值，该组牌的权重为：

  • 把这 nnn 个数划分为若干连续段
  • 同一段内元素取值都相同，相邻段的取值不同
  • 权重为所有连续段的平方之和

比如一组牌 【1,1,3,3,5,5,5,3,3】【1, 1, 3, 3, 5, 5, 5, 3, 3】【1,1,3,3,5,5,5,3,3】，对应权重为 22+22+32+22=212^2 + 2^2 + 3^2 + 2^2 = 2122+22+32+22=21。

求最小化的权重。

1≤l≤r≤1091\le l\le r\le 10^91≤l≤r≤109，n≤106n\le 10^6n≤106。

分析：

nnn 的范围到达 10610^6106，那复杂度接近 O(n)O(n)O(n)。

数列上的问题，很容易想到使用 dp 来解决。

那么我们需要考虑那些元素是必须要留下的：

  • 当前元素——val
  • 当前的代价——len
  • 已经连续的长度（用于递推计算代价）——res

但是 l,rl,rl,r 的范围太大，不可能每个可取的值都枚举一遍。

可以发现：当 r−l+1≥3r-l+1\ge 3r−l+1≥3 时，不管当前数怎么选，一定可以和左右不同，因此这种点可以直接不考虑。

那么现在需要考虑的每个数只有两种取值。

用正常数组来存储两维一定会爆空间，因此用 vector 来存储三个需要留下的元素。

但是最后可能的情况上限可以达到 2n2^n2n，仍然会 T，考虑优化：

  • 按照 val len res 的顺序从小到大排序
  • 如果 val 一样，那么 len 和 res 越小越好
  • 如果 val 不一样，存下排序的第一个即可

这样的话，每个 val 只会对应一个 len res，复杂度就可以控制在 O(n)O(n)O(n)。
